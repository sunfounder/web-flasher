GalaxyRVR 火星车 · 主板固件烧录

Arduino UNO（ATmega328P）· CH340 串口 · 浏览器直刷，不用装 avrdude / Arduino IDE

  1. 用 Chrome 或 Edge 打开本页（Web Serial 必须 https 或 localhost）。
  2. 火星车通电，USB 线接主板；把扩展板上的拨动开关拨到 Upload。
  3. 关掉 Arduino IDE、串口监视器等占着串口的软件。
  4. 下方选择固件版本（V2 或 V1），点「连接并烧录」，弹窗里选 USB-SERIAL CH340 对应的串口。
  5. 进度到 100% 后，把拨动开关拨回 Run，重新上电即运行新固件。

失败排查：没有弹窗 → 确认用 Chrome/Edge 且本页是 https 或 localhost；提示握手失败 → 确认开关在 Upload、串口没被占用、CH340 驱动已装好（设备管理器里应看到 USB-SERIAL CH340）。
