思天 QC 工具 · 固件烧录

ESP32-S3（LilyGO T-Display-S3，16MB Flash）· 整包镜像从 0x0 烧录

  1. 用 Chrome 或 Edge 打开本页（必须 https 或 localhost）。
  2. 下方选择要烧录的固件版本，确认参数提示正确。
  3. 用 USB 线把 QC 工具连到电脑，点「连接并刷机」，弹窗里选设备对应的串口。
  4. 进度到 100% 弹窗提示后，拔下 USB 再插上设备即启动（网页无法触发硬复位，这一步必做）。
  5. 开机后到设备「系统关于」核对版本号。

失败排查：弹窗没出现 → 确认用 Chrome/Edge 且本页是 https 或 localhost；选错串口/提示失败 → 重拔 USB 再试。
