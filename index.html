固件烧录工具集

Web Flasher · 浏览器直连设备烧录（Web Serial），无需安装驱动/软件

  1. 用 Chrome 或 Edge 打开本页（本页必须运行在 https 或 localhost 下才能连设备）。
  2. 下方选择要烧录的固件，确认目标设备/参数提示正确。
  3. 用 USB 线把设备连到电脑，点「连接并刷机」，弹窗里选设备对应的串口。
  4. 进度到 100% 提示完成后，如设备没有自动重启，拔下 USB 再插上即可。

失败排查：弹窗没出现 → 确认用 Chrome/Edge 且本页是 https 或 localhost；选错串口/提示失败 → 重拔 USB 再试。
